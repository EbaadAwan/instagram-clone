# Instagram Clone
This is another solo project that focuses on essential CSS and HTML. The purpose of this mini solo project was to clone Instagram by selecting one post from a JavaScript array and using hardcoded data along with semantic HTML to render an Instagram clone. Hover effects were also added to the icons to simulate the feel of the app. This project idea came from Scrimba’s Fullstack Developer Path, where students are given solo projects to complete after each module or set of lessons. Because this project was built in the Scrimba environment, there may be a lot of whitespace when running the program.

# Getting Started
Install the dependencies and run the project
```
npm install
npm start
```
